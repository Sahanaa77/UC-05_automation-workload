# build-phase
Build exactly one phase of WorkloadLens from the spec docs.

## Steps
1. Read AGENTS.md and docs/BUILD_PLAN.md. Identify the phase number from my message (default: first unchecked phase).
2. Read only the docs that phase needs (listed in its "Reads" line).
3. Write a plan of ≤10 lines.
4. Implement every task in that phase, complete files in one pass.
5. Run the phase's verification commands in the terminal. Fix failures yourself.
6. Tick the phase checkboxes in docs/BUILD_PLAN.md and log decisions.
7. Reply in ≤5 lines: what's done, how to run it. Stop.
